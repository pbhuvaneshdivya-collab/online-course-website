# SkillSpring — Online Course Website

A responsive online learning website built with HTML5 and CSS3.

## Run
Open `index.html` in a browser.

## Included
- Course categories and featured course cards
- Instructor profiles and learner testimonial
- Responsive layout for desktop, tablet, and mobile
- Navigation links between page sections

This is a front-end demonstration. Course links are page navigation only; no real enrolment, login, or payment backend is connected. Replace sample course and instructor details before presenting it as a real service.
